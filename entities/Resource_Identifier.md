# Resource Identifier

## Definition
An identifier that is assigned to a [Resource](../entities/Resource.md).

## Attributes

principal : [Boolean](../datatypes/Boolean.md) – whether this identifier is the principal one for the Resource it identifies, i.e. the identifier the Resource is primarily registered or published with; other identifiers attached to a Resource are supplementary

## Relationships

<a name="rel__is-assigned-to">is-assigned-to</a> / [has-identifier](../entities/Resource.md#user-content-rel__has-identifier) : A Resource Identifier can be assigned to a [Resource](../entities/Resource.md).
